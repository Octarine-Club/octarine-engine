11// Per-file asset metadata, parsed from an optional `<file>.meta` Lua sidecar. A missing sidecar
12// means "all defaults". Each struct owns an `applyDefaults(...)` that fills any unset field from
13// project-wide defaults (GameConfig) and the constants below, so downstream code always sees a
14// fully-resolved struct. These types depend on nothing engine-specific (no SDL) so they can be
15// unit-tested in isolation.
