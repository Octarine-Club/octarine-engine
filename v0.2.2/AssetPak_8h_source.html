13// Packed archive of baked assets and scripts, opened as a single blob at startup.
14//
15// Format ("OCPK", little-endian):
16// [56] PakHeader:
17// char magic[4] = "OCPK"
18// u32 version = 1
19// u64 tocOffset
20// u32 tocCount
21// u32 flags (bit 0: ChaCha20 encrypted)
22// u8 salt[16]
23// u8 tocMac[16] (128-bit keyed MAC over header metadata + TOC)
24// [data...] ChaCha20-encrypted asset payloads
25// [TOC...] Encrypted array of PakTocEntry:
26// u64 pathHash (64-bit FNV-1a of normalized project-relative path)
27// u64 offset (from file start)
28// u64 size
29//
30// Filenames and directory hierarchies are never stored in the archive. Data is decrypted
31// on-the-fly at 64-byte block granularity via an SDL_IOStreamInterface backed by ChaCha20, so
32// `data_` remains completely encrypted in RAM.
