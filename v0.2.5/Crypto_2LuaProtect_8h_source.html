12// Scrambled Lua 5.4 binary chunks: starts with \x1bOCT\x54\x00\x19\x93. Restores standard

14// package key, and unmasks string constants in place.

16// When `requireProtected` is true in strict shipped builds (OCTARINE_SHIPPED &&
17// OCTARINE_PROTECT_SCRIPTS && !OCTARINE_ALLOW_LOOSE_ASSETS), unprotected plaintext scripts are
18// rejected and cleared.
