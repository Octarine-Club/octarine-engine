5// Bake-time audio loudness normalizer for assets configured with `meta.normalize = true`.
6//
7// Implements ITU-R BS.1770-4 integrated loudness measurement: a K-weighting filter chain
8// (pre-filter high-shelf + RLB high-pass) feeds 400 ms gated mean-square blocks at 75% overlap;
9// the integrated loudness uses both the absolute (-70 LUFS) and relative (-10 LU below ungated
10// mean) gates per spec. Gain is applied uniformly to reach the target loudness; samples that
11// would clip int16 are hard-clamped.
12//
13// Supports PCM 16-bit WAV (mono or stereo, arbitrary sample rate). Filter coefficients
14// are derived per sample rate via bilinear transform of BS.1770 analog prototypes.
15class AudioNormalizer {
16 public:
17 // Read `srcPath`, measure integrated loudness, apply the gain needed to land at
18 // `targetLufs`, write the result to `dstPath`. Returns false on unsupported format, I/O error,
19 // or a signal too quiet to measure (everything below -70 LUFS absolute gate). On false the
20 // caller should fall through to shipping the original.
21 static bool NormalizeWav(const std::string& srcPath, const std::string& dstPath, double targetLufs = -16.0);
22
23 // Pure measurement — no file write. Returns the integrated loudness in LUFS, or NaN when the
24 // signal is entirely below the -70 LUFS absolute gate. Exposed so the test can verify the
25 // post-normalize loudness lands at the target without re-implementing the analyzer.
26 static double MeasureWavLufs(const std::string& wavPath);
27};
