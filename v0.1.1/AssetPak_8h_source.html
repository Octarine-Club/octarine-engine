12// One-file archive of every baked asset, opened as a single SDL_LoadFile blob at startup. Each
13// entry is referenced by its project-relative path (forward slashes), matching the `file` field
14// AssetCatalog::WriteManifest serializes — so a lookup driven from `fullPath - basePath` resolves
15// cleanly to the same key the manifest uses.
16//
17// Format ("OCPK" v1, little-endian):
18// [16] magic="OCPK" | u32 version=1 | u64 toc_off | u32 toc_count | u32 reserved
19// [data...] raw blob bytes concatenated in TOC order
20// [TOC...] repeated `toc_count` times:
21// u64 offset (from file start)
22// u64 size
23// u16 path_len
24// char path[path_len] (no trailing NUL)
25//
26// Whole-file load: the pak gets read into memory once via SDL_LoadFile and each Open() returns an
27// SDL_IOFromConstMem slice over the cached buffer. Memory cost ≈ total baked asset bytes — fine
28// for indie shipping budgets; if a project ever needs lazy reads, swap the impl to a custom
29// SDL_IOStreamInterface backed by pread() and the lookup map stays unchanged.

39 // Pack every entry in `catalog` into a single .pak at `outPath`. Each entry's `fullPath` is
40 // read and stored under its project-relative form (`fullPath` re-rooted against `basePath`,
41 // forward-slashed). `extraFiles` lets the bake step include derived artifacts (glyph atlases,
42 // audio bakes, etc.) that don't live in the asset catalog — each is read + stored under its
43 // own project-relative form. `pathOverrides` re-routes a catalog entry's *source* bytes to an
44 // alternative path while keeping the original relPath in the pak — used by the audio
45 // normalize pass to swap normalized WAVs in for their originals at packing time without
46 // mutating the source tree. Duplicates against catalog entries are silently dropped (first
47 // write wins). Returns false on any I/O failure; partially-written paks are removed.

50 const std::map<std::string, std::string>& pathOverrides = {});
