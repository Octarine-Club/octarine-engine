15// Shared boot-sequence phases used by both Game::Setup (full per-frame loop) and
16// Game::RunBakeValidation (headless asset bake). Each phase is independent — callers compose
17// the subset they need — but the *order* of phases follows the dependency rules baked into
18// the engine (e.g. EntityPoolManager must be Set before ProjectileEmitSystem::Init, Lua
19// libraries must be open before ScriptSystem::CreateLuaBindings, modules install after
20// component bindings).
21//
22// Why a namespace of free fns instead of a class: there's no state to hold between phases.
23// Each fn takes exactly the inputs it needs, returning a reference where one is useful
24// downstream (InstallInputSystem → InputSystem& for LuaSystemRegistry registration, etc.).
25//
26// Centralizes the common setup sequence across interactive engine runs and
27// headless asset baking to keep bindings and singletons consistent.
28namespace engine_bootstrap {
29// Open the Lua libs every startup script + module install assumes (base, math, io, string,
30// table) and override `dofile` so it loads through SDL_IOFromFile — required for chunks
31// loaded out of an APK / .app bundle, harmless on a real filesystem.
32void InstallLuaLibraries(sol::state& lua);
33
34// Set the engine-level Registry singletons that the startup script + Lua modules read at
35// install time: RenderQueue, CameraComponent (sized to the window), AssetManager,
36// ViewportInfo, and — on the live-frame path only (withFramePathCaches; bake skips them since
37// no frames render and no audio systems run) — the entity-keyed backend-handle caches
38// SpriteRenderCache and AudioTrackCache. Also plumbs the freshly-Set AssetManager pointer onto
39// the EngineContext; other context fields must already be populated by the caller.
40void InstallCoreSingletons(Registry& registry, EngineContext& context, int windowWidth, int windowHeight,
41 bool withFramePathCaches, sol::state* lua = nullptr);

43// EntityPoolManager + GameModule singletons (e.g. ProjectileEmitSystem). Both bind Lua
44// surfaces (fire_projectile), so registration must happen before InstallLuaModules.
45void InstallPoolAndSingletons(Registry& registry);
46
47// InputSystem owned by the Registry + subscribed to its three input events. The `input.*`
48// Lua surface is installed later via LuaSystemRegistry::bindAll once Lua libs are open;
49// this phase wires the engine-side instance + EventBus subscriptions.
50InputSystem& InstallInputSystem(Registry& registry, const std::unique_ptr<EventBus>& eventBus);

52// RegisterAllLuaBindings + (when OCTARINE_WITH_EDITOR is on) RegisterAllComponentInspectors.

54// Must run before InstallLuaModules so usertypes exist when modules reference them.
55void RegisterAllComponentBindings();

57// Invoke RegisterAllLuaModules — installs every free-function module global the startup

60void InstallLuaModules(sol::state& lua, Game& game);
