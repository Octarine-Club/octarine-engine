24 // Request a scene swap. Once the frame loop is running (its first FlushPendingSceneLoad arms
25 // deferral), this only records the path; the actual swap runs at the next FlushPendingSceneLoad()
26 // — i.e. the top of FrameLoop::Update, outside any event dispatch / system ForEach. That deferral
27 // is what makes it safe for a UIButton on_click handler to navigate: doing the swap inline would
28 // clear + recreate entities in the same archetype chunk UIButtonSystem is mid-iteration over,
29 // re-firing the click on a freshly created (and not-yet-transformed, so positioned at the origin)
30 // button. Before deferral is armed (bake + the initial startup load) the swap happens immediately.
31 // This is the entry the Lua `load_scene` global and the editor toolbar drive through.
32 void RequestLoadScene(const std::string& scenePath);
33
34 // Immediate, unconditional scene swap. RequestLoadScene/FlushPendingSceneLoad call this; external

40 // Arm deferral (first call) and perform a pending deferred swap, if any. Called at the top of the
