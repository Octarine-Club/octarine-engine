7// Bake-time texture atlas packer. Walks the catalog for entries whose `atlas` field is set (and
8// `no_atlas` is not), groups them by atlas name, packs each group into one square PNG written
9// under `<basePath>/_atlases/<group>.png`, and mutates the member entries to record their slice
10// inside the atlas (`atlasId` + `atlasSlice`). It also adds one new CatalogEntry per atlas group
11// (id = `__atlas_<group>`, type = Texture) so the runtime can resolve the atlas as a normal
12// loadable texture.
13//
14// Pure bake-time helper: never invoked in a running game, only from Game::RunBakeValidation. The
15// stb_image + stb_image_write + stb_rect_pack implementation is compiled into the engine binary
16// behind this single translation unit so the runtime cost is one extra .o on the link line.
17class TextureAtlasBaker {
18 public:
19 // Default padding (transparent gutter) between packed sprites, in pixels. Avoids bilinear
20 // bleed at atlas boundaries — most sprite-packs end up with this exact value.

23 // Default maximum atlas dimension. SDL3 GPU backends commonly cap at 4096 or 8192; 4096 is
24 // the conservative default that survives every shipping target the engine claims. A group
25 // whose sprites won't fit fails the bake (no silent fallback to multiple atlases — this
26 // keeps the manifest one-atlas-per-group, and forces the project author to split or shrink
27 // their art instead of silently producing 5x the textures).
28 static constexpr int kDefaultMaxAtlasDim = 4096;
29
30 TextureAtlasBaker() = default;

32 // Pack every atlas group declared by `catalog`. Writes `<basePath>/_atlases/<group>.png` for
33 // each, mutates member entries to point at the atlas, and inserts the new atlas entries.
34 // Returns false on any image load failure, pack failure, or PNG write failure. Idempotent
35 // across runs: the same input catalog + sources produce the same atlas bytes (member ordering
36 // is the catalog's std::map id order, packing seeds are deterministic per stb_rect_pack).
