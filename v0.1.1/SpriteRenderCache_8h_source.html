10// Render-side cache mapping Entity -> last-resolved SDL_Texture* + atlas-slice origin + the
11// AssetManager texture-generation the values were resolved against. Lives in the render layer
12// so SpriteComponent stays POD (no SDL handles in game data). For atlas-packed assets, the
13// slice origin is added to the sprite's logical srcRect during emit so the same script-level
14// (sx, sy) selects inside the packed atlas; loose textures leave the offset zero (no-op add).
15//
16// Single-threaded: callers must serialize Store/Forget/Clear. RenderSpriteSystem warms the
17// cache in a serial Prepare pass and reads it in the parallel emit pass — never inserts under
18// ParallelForEach because std::unordered_map cannot tolerate concurrent writes.

30 if (const auto it = entries_.find(entity.GetId()); it != entries_.end() && it->second.generation == currentGen) {
