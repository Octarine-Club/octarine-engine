6// Serializes a Lua table to a loadable Lua literal (the body after `return `). Backs
7// storage.write_table / project.write_table; the inverse is a plain load() of the file with an
8// empty environment (see StorageModuleLuaBinding), so the emitted text must be pure data — no
9// identifiers, no library calls.
10//
11// Supported: nested tables, strings, numbers (integer subtype preserved; non-finite values emit
12// the env-free expressions 1/0, -1/0, 0/0), booleans. Keys may be numbers, strings, or booleans.
13// Functions, userdata, threads, and cyclic tables are errors — the caller gets false + a message
14// rather than a silently incomplete save.
15//
16// Output is deterministic (number keys ascending, then string keys lexicographic, then false,
17// true) so emitted files diff cleanly under version control — project.write_table output is
18// expected to be committed to game repos.
