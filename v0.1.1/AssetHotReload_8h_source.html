15// Local-disk asset hot reload: the editor/player counterpart to ScriptHotReload, but for content
16// instead of code. Owns a FileWatcher over the source files of every currently-resident asset
17// (textures / fonts / audio clips) and, when one changes on disk, calls AssetManager::ReloadByPath
18// to swap the underlying SDL_Texture* / TTF_Font* / MIX_Audio*. Consumers re-resolve for free:
19// sprite renderers poll AssetManager::TextureGeneration(), and audio is looked up by id on each
20// play, so no reload event is needed.
21//
22// One instance lives in the Registry singleton set; ticked from the main loop (FrameLoop::Update)
23// behind the same EngineOptions.hotReloadEnabled gate the script reloader uses. Compiled out under
24// OCTARINE_SHIPPED.
25//
26// Scope: this watches the loose source tree, so it is the dev/editor inner-loop path. The remote
27// hot-push path (DevListenDispatch) drives the same AssetManager::ReloadByPath directly.
